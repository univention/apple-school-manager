.. _glossary:

********
Glossary
********

.. glossary::
   :sorted:

   Apple School Manager
      The web service with which educational institutions manage their Managed
      Apple Accounts, devices, and content.
      Abbreviated as ASM.

   App Center
      The Univention App Center,
      the component of :term:`UCS` with which you install and configure apps.

   Keycloak
      The identity and access management software that UCS ships as an app.
      It provides the single sign-on of the domain.

   OIDC
      OpenID Connect,
      the identity layer on top of OAuth 2.0.

   PKCE
      Proof Key for Code Exchange,
      an extension of the OAuth 2.0 authorization code flow.

   SSF
      Shared Signals Framework,
      the standard of the OpenID Foundation for sharing security events between
      an identity provider and the applications that rely on it.

   UCR
      Univention Configuration Registry,
      the central configuration database of :term:`UCS`.

   UCS
      Univention Corporate Server,
      the server operating system with integrated identity management.

   UCS@school
      The extension of :term:`UCS` for schools and school authorities.

   UMC
      Univention Management Console,
      the web interface for the administration of :term:`UCS`.
